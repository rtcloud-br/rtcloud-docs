# Hardware

Fonte: [rtcloud.com.br](https://rtcloud.com.br) · [rtcloud.com.br/hardware](https://rtcloud.com.br/hardware)

Todos os planos RTCloud usam a mesma linhagem de servidor — o que muda é a **cota** de RAM, vCPU e recursos do painel.

## Destaques

- **AMD EPYC · Infinity Guard** — arquitetura empresarial com isolamento e segurança nativos
- Processamento pensado para bots, APIs e sites 24/7
- RAM de alta frequência (cold starts mais curtos)
- **SSD NVMe** empresarial (deploy, logs, I/O)
- Rede ativa com múltiplos nós / rotas / regiões (métricas exibidas no site)
- Proteção **DDoS**; rede de **10 Gbps** a partir do Carbon (conforme o site)

Ideal para carga contínua: bots Discord, sites, APIs e automações com uptime estável.
