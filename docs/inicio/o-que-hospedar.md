# O que você pode hospedar

Fonte: [rtcloud.com.br](https://rtcloud.com.br) · [rtcloud.com.br/hospedagem](https://rtcloud.com.br/hospedagem)

## Bot de Discord

discord.js, discord.py, JDA, Discordeno — reinício automático e console ao vivo no painel.

## Bot de WhatsApp

Baileys, whatsapp-web.js, Venom, WPPConnect — QR Code no console, sessão salva, 24 horas.

## Bot de Telegram

python-telegram-bot, aiogram, Telegraf, grammY — token em variável de ambiente.

## Sites e lojas

Next.js, React, Vue, Express (+ PHP / HTML) — `nome.rtsystems.app` ou domínio próprio, HTTPS automático, deploy pelo GitHub, limpeza de cache no painel.

## APIs Node.js e Python

Express, Fastify, NestJS, FastAPI, Flask, Django — HTTPS, env, logs ao vivo, métricas de latência por rota.

## Banco de dados dedicado

MongoDB, PostgreSQL, MySQL e Redis — memória reservada, TLS, endereço próprio, backup com um clique.

## APIs de alto tráfego

Até **16 vCPU** e **32 GB de RAM** nos planos de tabela; até **10 instâncias** no mesmo domínio. Acima disso: plano **Obsidian** (48 GB a 768 GB), assinado por Pix.

## Linguagens aceitas

Node.js (JS/TS), Python, Java, Go, Rust, PHP, Ruby, .NET/C#, Elixir e HTML estático — versão escolhida por aplicação.
